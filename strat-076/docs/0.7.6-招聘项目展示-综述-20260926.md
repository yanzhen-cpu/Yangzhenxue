# STRAT-032 v0.7.6 招聘项目展示综述

## 核心结论

本案例展示已冻结并独立审计的商品期货估值与连续换月研究回测。正式运行 `STRAT032-FULL-MAIN-20260926` 覆盖2019-01-02至2026-09-24，初始权益100万元，期末权益5170.33万元，累计收益5070.33%，年化66.64%。最大平仓回撤29.86%，普通最大回撤46.20%，Sharpe 1.66。55个完整周期全部平仓，实际换月10次。

## 工程证据

本轮专项测试141项通过，独立审计断言865801条通过；正式包的1877个权益日、164条成交和55个周期与输出完整性审计一致。公开代码页展示从正式运行冻结源码快照复制的 `strat_032_data.py` 与 `strat_032_engine.py`，两文件依赖的前序引擎不在公开包中。

## 2026年度口径

年度表以 `equity_daily.csv` 中逐年最后交易日权益计算。2026年至9月24日相对2025年末，账户权益增加616.76万元，增幅13.54%。正式指标 `by_year` 中按最终退出年份归集的六个完整周期净盈亏为993.27万元；跨年持仓和换月分腿的确认时点使两种口径不同。

## 结果边界

55个周期中29个带未来锚标记；部分历史交割月价的当时可知性未逐月独立证明，正式数据源质量标记为PARTIAL。日频撮合与开盘批次预算是近似，手续费和滑点为零。该结果是冻结假设下的历史模拟，不是实盘业绩。
