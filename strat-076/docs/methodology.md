# STRAT-032 v0.7.6：公开方法说明

## 研究对象

本案例对应正式运行 `STRAT032-FULL-MAIN-20260926`，账户从2019-01-02至2026-09-24，初始资金100万元，覆盖34个商品品种的数据范围。0.7.6在已冻结的前序策略上，把普通新建时的排畸筛选固定为LC、PD、PS、PT、SI、MA、SH、UR、AG九个品种代码。普通资讯条件停用；保证金公告的可得时点仍参与风险管理。

## 策略链路

1. 用具体合约的日频价格、交割估值锚、动态方向保证金率、合约生命周期、交割标准与成交量构造当日快照。
2. 严格按筛选层、执行层顺序处理普通新建；持仓的保护退出不重过普通筛选。
3. 合约进入交割前月末生命周期强退时，可依据前一交易日已知价格和成交量选择远月合约，按同手数提交限价单，最多等待五个交易日。
4. 换月成功后保留原交易周期的分类、原始开仓保证金率、时钟和保护状态，并按跨月价差平移策略价格阈值；新合约会计成本按真实成交价另行记录。
5. 提保公告、风险预算、品种束冲突、账户强退和禁仓由事件状态机统一执行。

## 指标口径

- 累计、年化收益与普通最大回撤取正式运行 `metrics.json`。
- 最大平仓回撤取 `additional_drawdowns.csv` 中已实现权益回撤的最大值，为29.86%；普通最大回撤为46.20%。
- 年度表使用 `equity_daily.csv` 的年末账户权益逐年相减，包含当时未平仓浮盈浮亏；2026年为截至9月24日的样本内变化。
- `metrics.json` 的 `by_year` 按最终退出年份归属完整交易周期净盈亏。一个周期可能跨年并发生换月分腿，因此它与当年账户权益变化不是同一个量。

## 审计与限制

正式包记录55个已平仓周期、10次实际换月、164条成交、1877个权益交易日；本轮141项专项测试及865801条独立审计断言通过。55个周期中29个带未来锚标记；历史月价的当时可知性没有逐月独立证明，源质量标记为PARTIAL。日频阈值成交、同批权益预算和市场容量是研究近似，手续费与滑点均为0。该结果是冻结假设下的历史模拟，不是实盘业绩。
