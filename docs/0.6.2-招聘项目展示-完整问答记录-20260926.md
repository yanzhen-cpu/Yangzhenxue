# 0.6.2招聘项目展示完整问答记录

## 用户目标

用户需要把一个策略作为项目成果上传到招聘网站。招聘网站只提供一个可粘贴链接的位置，因此采用公开GitHub仓库与GitHub Pages单链接展示方案，并指定以策略0.6.2为案例。

## 执行要求

1. 建立独立项目和目录规范。
2. 只读使用0.6.2冻结规范与正式回测结果，不修改原正式运行。
3. 制作招聘方可在30秒内识别项目价值的单页网站。
4. 提供招聘版PDF、公开代码节选、结构化指标和方法说明。
5. 对关键指标逐项追溯到正式运行。
6. 执行桌面端、移动端、链接、敏感信息、占位符和内容一致性检查。
7. 本地验证通过后提交Git，并发布到用户指定的公开GitHub仓库。

## 数据与指标映射

- 累计收益、年化收益、Sharpe、胜率和平均盈亏比来自正式运行指标文件。

- 分年度盈亏来自正式运行的年度已实现盈亏汇总。
- 测试数、审计断言数、成交数、持仓日数和正式审计状态来自正式测试与审计记录。

- 首屏展示项目定位、正式运行身份和六项核心指标。
