# 方法说明

## 研究目标

策略0.6.2研究商品期货价格相对交割估值锚出现显著偏离后的均值回归机会。系统把机会发现和订单执行分为严格有序的两层，并在账户层统一处理保证金、方向暴露、品种束相关性和强制退出。

## 数据范围

- 回测区间：2021-01-04至2026-08-07。
- 品种范围：34个非农商品品种。
- 行情：活动具体合约的日频开高低收、结算、成交量和持仓量。
- 估值锚：交割月结算信息及经确认的研究型月价算法。
- 风险参数：分合约、分交易日的交易所保证金率及有来源标记的延续规则。
- 元数据：上市时间、主力身份、合约周期、交割标准与品种束。
- 资讯：有记录时按照可得时间使用；缺失日期视为没有资讯。

## 策略结构

1. 在每日收盘后完成品种成熟度、交割标准、估值下沿和期货偏离筛选。
2. 按资讯、偏离得分、持仓品种束冲突和临近交割时间依次择优。
3. 在下一交易日生成限价计划，并按照对冲优先级和统一账户预算执行。
4. 对非极值和极值品种分别执行建仓、加仓、止损、回归退出和后20日管理。
5. 每日复算多空保证金、净方向风险、总风险和组合强制退出条件。
6. 所有成交进入统一逐日盯市和逐笔审计链。

## 审计方法

- 使用真实短窗验证信号、成交、加仓和退出链路。
- 对完整历史运行执行693项测试。
- 对32个完整交易周期和1356个交易日执行95686项独立断言。
- 从成交记录重新计算逐日权益、已实现盈亏、未实现盈亏和保证金占用。
- 检查报告、曲线、逐笔表和结构化指标是否同源。

## 解释限制

主结果使用零手续费和零滑点。日频高低价只能证明阈值曾被触及，不能还原盘中事件先后；开盘批次使用统一权益快照近似预算。部分交割估值采用经确认的研究假设，并在正式运行中保留未来锚标记。因此，本结果是可审计的研究回测，不是实盘收益记录。
